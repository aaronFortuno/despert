# Changelog

## 1.0.0 — 2026-10-24

First public release.

- One-click, indefinite active/inactive switch and monochrome cup icons for light/dark taskbars.
- Fixed 45-second idle interval, Windows power requests, and zero-displacement mouse events; no keyboard, clicks, or wheel input.
- Pause during lock, suspension, or session disconnection; resume the user's active intent within the same process.
- Optional per-user Windows startup, initially unchecked. Each process opens inactive.
- Native tray menu with no informational success popups or taskbar-visibility walkthrough.
- About dialog with author, repository, portfolio, MIT license, and optional Value for Value address copying.
- English, Catalan, Spanish, Basque, and Galician, selected by Windows display language with English fallback.
- Portable, source, and complete archives; pinned build tools, SHA-256 manifests, and byte-for-byte executable verification.

Earlier 0.x versions were local development iterations. Their reviews are in `docs/REVISIO-*.md`.
