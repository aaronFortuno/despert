First public release of **Despert**, a small open-source Windows tray app to keep your computer awake with one click.

- Steam on the cup means active; no steam means inactive.
- Optional per-user Windows startup. Every new process starts inactive.
- Native context menu and light/dark monochrome cup icons.
- About dialog with source, author portfolio, MIT license and optional Value for Value contribution details.
- English, Catalan, Spanish, Basque and Galician, following the Windows display language. English fallback for other languages.

Requires **Windows 10/11 and .NET Framework 4.8**. Portable, with no installer, administrator rights, runtime packages, accounts or telemetry. Close any older copy before opening this version.

**Downloads**

- `Despert-1.0.0-portable.zip`: ready to use.
- `Despert-1.0.0-source.zip`: complete source and build instructions.
- `Despert-1.0.0-complete.zip`: matching executable and source together; recommended for auditing.
- `Despert-1.0.0-SHA256SUMS.txt`: archive checksums.

The complete package supports byte-for-byte executable verification using the pinned build tools. See [verification instructions](https://github.com/aaronFortuno/despert/blob/main/docs/VERIFYING.md).

Original code and artwork: **MIT**. Local automated checks pass, including all five languages and passive About layouts. The idle mechanism has been confirmed for more than two hours on one managed education computer; behavior on other managed devices depends on their configuration. Interactive checks on the user's device remain manual.
