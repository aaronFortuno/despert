**Despert 1.0.1** adds the author's existing Lightning QR to the optional Value for Value section in About. The address and copy button remain available.

The QR is embedded locally and drawn with crisp black/white modules. It uses no external QR service, payment SDK, or new runtime dependency. Its description is available in all five interface languages.

**Signing status:** this portable executable is still unsigned. Windows may show **Unknown publisher** or a SmartScreen reputation warning. The QR update and file metadata do not remove that warning. See [signing status and evaluated options](https://github.com/aaronFortuno/despert/blob/main/docs/SIGNING.md).

Requires Windows 10/11 and .NET Framework 4.8. Close the previous copy before opening this version.

Downloads: **portable.zip** to use the app, **source.zip** for code, or **complete.zip** for matching executable and source. The SHA-256 manifest covers all three archives. The unsigned executable remains reproducible byte for byte from the supplied source and pinned build tools.

Code and artwork: MIT. Checks were performed locally; interactive checks on the managed device remain manual.
